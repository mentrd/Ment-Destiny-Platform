# 星語命理平台 — UI／UX 設計文件

> 版本：1.0｜日期：2026-07-19

---

## 1. 設計理念

**神秘、療癒、現代** — 以「夜空觀星」為核心意象：使用者像在星空下與一位溫柔的引路人對話，而不是走進昏暗的算命攤。整體避免老派命理網站的紅黃配色、跑馬燈與過度迷信的視覺語彙。

三個設計關鍵字：

| 關鍵字 | 落實方式 |
|---|---|
| 神秘 Mystic | 深夜藍底、星空粒子背景、金色點綴、襯線字標題 |
| 療癒 Healing | 大量留白、柔和圓角、緩慢的漂浮/閃爍動畫、溫和文案 |
| 現代 Modern | 卡片式資訊架構、玻璃擬態（backdrop-blur）、清楚的操作動線 |

## 2. 設計系統（Design Tokens）

### 2.1 色彩

| Token | 色值 | 用途 |
|---|---|---|
| `night-900` | `#070b1a` | 最深底色（頁首/頁尾/後台側欄） |
| `night-800` | `#0b1026` | 頁面主底色 |
| `night-700/600` | `#121a3a / #1a2450` | 卡片漸層、輸入框底 |
| `mystic-500/400/300` | `#6d5bd0 / #8b7ae8 / #b3a6f5` | 主品牌紫：連結、次要按鈕、標籤 |
| `gold-500/400/300` | `#d4af37 / #e6c860 / #f2dd9b` | 金色：主 CTA、吉、重點數字、星級 |
| `rose-400` | `#e58bb0` | 感情類點綴、錯誤/凶提示 |
| `ink-100/300/500` | `#eef0fb / #c3c8e8 / #8f96c2` | 主文/副文/弱化文字（對比符合 WCAG AA） |

色彩語意：**金色＝吉／行動**、**紫色＝導覽／中性**、**玫瑰＝感情／警示**、五行另用 木綠/火紅/土黃/金白/水藍。

### 2.2 字體
- 標題：**Noto Serif TC**（襯線，儀式感）
- 內文/介面：**Noto Sans TC**
- 特大數字（配對分數、生命靈數）：襯線 + 金色漸層 `text-gradient-gold`

### 2.3 元件庫

| 元件 | 樣式 |
|---|---|
| `card-mystic` | 深藍漸層卡 + 紫色細邊框 + blur，hover 上浮 4px、邊框轉金 |
| `btn-gold` | 金色漸層膠囊主按鈕，高度 ≥44px，hover 發光 |
| `btn-ghost` | 紫色描邊透明次按鈕 |
| `input-mystic` | 深底圓角輸入框，focus 紫色光圈，錯誤時紅框 + 欄位下紅字 |
| `divider-star` | ✦ 星形分隔標題（兩側金色漸層線） |
| `StarRating` | 1–5 金星（運勢指數） |
| Toast | 結果頁操作回饋（已收藏/已複製） |

### 2.4 動效
- `twinkle`：星空粒子閃爍（背景，70 顆固定種子星星，SSR 一致）
- `float-slow`：月亮/水晶球漂浮
- `spin-slow`：儀式載入的星盤雙環反向旋轉
- `card-flip`（rotateY + preserve-3d）：塔羅翻牌
- `shake`：籤筒搖籤
- `coin-toss`：易經擲幣（translateY + rotateX 三圈）
- `rise-in` / `rise-stagger`：結果區塊依序浮現
- 全站支援 `prefers-reduced-motion`（動畫自動停用）

## 3. 版面系統（RWD）

| 斷點 | 佈局 |
|---|---|
| `<640px` | 單欄；功能卡 1–2 欄；紫微命盤改 2 欄卡片列表；底部固定 5 鍵快捷列（首頁/運勢/全部功能/紀錄/我的） |
| `640–1024px` | 卡片 2–3 欄 |
| `>1024px` | 卡片 4 欄；頂部下拉導覽；快捷列隱藏 |

觸控目標一律 ≥44px；表格類內容（命盤、行星表）在窄螢幕使用 `overflow-x-auto`。

### 4.2 功能三頁式動線（所有算命功能一致）

**介紹頁**（SEO 入口）→ **輸入/互動頁** → **結果頁**

- 介紹頁：功能簡介、原理科普、模式選擇卡、FAQ（含 FAQPage 結構化資料）、麵包屑、金色 CTA
- 輸入頁：表單分組清楚、select 為主減少打字、即時驗證、送出後進入 2.6 秒儀式載入（旋轉星盤 + 三段引導語「靜下心，深呼吸…」）
- 結果頁（統一由 `ResultShell` 組裝）：
  1. 結果主視覺（牌卡/命盤/大數字，`rise-stagger` 依序浮現）
  2. 分析內容區塊
  3. 動作列：`🔄 重新測算｜☆ 收藏｜🔗 複製連結｜📘 FB｜💬 LINE｜📸 IG 分享圖`
  4. 免責聲明（固定顯示）
  5. 「你可能也想試試」相關功能 ×3

### 4.3 特色互動設計

| 功能 | 儀式感設計 |

| 塔羅 | 洗牌 → 牌背扇形展開 → 點選 → 3D 翻牌；逆位牌上下顛倒呈現 |

## 5. 文案語氣指南
- 溫柔、鼓勵、給選擇而非下判決：「適合…」「留意…」「不妨…」
- 禁止：保證發財、保證復合、疾病預測、恐嚇式解讀（「必有血光」）
- 凶/下籤一律附「這是提醒不是判決」的緩衝語
- 健康相關內容只給生活提醒（作息、飲水、紓壓），並導向專業醫療

## 6. 無障礙
- 文字對比 AA、表單 label 綁定、錯誤 `aria-invalid`、動作回饋 `role="status"`
- 星級、圖形均附 `aria-label` 文字替代
- 鍵盤可完成主要流程；`prefers-reduced-motion` 支援

## 7. 後台設計
工具導向的同主題深色介面：左側固定選單（手機收合）、主區白紙卡片、表格 + 行內編輯表單、統計以 CSS 橫條/長條圖呈現，避免引入圖表套件。
