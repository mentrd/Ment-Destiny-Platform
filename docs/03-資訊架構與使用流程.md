## 2. 核心使用流程

### 2.1 通用測算流程（表單型：八字/紫微/占星/姓名/靈數/解夢）

```
使用者
  │
  ▼
首頁功能卡片 ──或── 搜尋引擎直達介紹頁
  │
  ▼
功能介紹頁（原理說明、FAQ、範例結果預覽）
  │  [開始測算]
  ▼
資料輸入頁
  │  填寫 → 即時格式驗證 ──✗── 欄位下方錯誤提示，修正後再送出
  │  ✓
  ▼
儀式感載入動畫（2–3.5 秒：星空粒子/羅盤旋轉）
  │
  ▼
結果頁（URL 帶編碼參數 → 可重現、可分享）
  │
  ├─ [重新測算] → 回輸入頁（保留原輸入）
  ├─ [分享] → 產生分享圖 / 複製連結 / FB / LINE / IG
  ├─ [收藏] → 未登入存 localStorage；已登入同步伺服器
  └─ [相關推薦] → 其他功能介紹頁（交叉導流）
```

### 2.2 互動型流程（塔羅/抽籤/易經擲幣）

```
介紹頁 → 選擇牌陣/籤種 → （可選）輸入問題
  │
  ▼
互動階段
  塔羅：點擊洗牌 → 牌背扇形展開 → 逐張點選（1 或 3 張）→ 翻牌動畫
  抽籤：默想問題 → 點擊籤筒 → 搖籤動畫 → 籤支彈出
  易經：連續擲幣 6 次（每次動畫 + 記錄爻）→ 成卦
  │
  ▼
結果頁（同 2.1 通用結果功能）
```

### 2.3 每日運勢回訪流程

```
使用者（回訪）→ 首頁「今日運勢」列 → 點選自己的星座
  → /horoscope/daily/[sign]（當日內容，全站相同 → SEO 可收錄）
  → 頁尾：其他星座捷徑 + 週/月運勢 + 相關功能推薦
```

### 2.4 會員與紀錄流程

```
任一結果頁 [收藏]
  ├─ 未登入 → 存 localStorage → 顯示提示「登入後可跨裝置保存」
  └─ 已登入 → POST /api/favorites → /me/favorites 可見

註冊 → 同意條款（必勾）→ 建立帳號 → 自動登入
  → 若 localStorage 有紀錄 → 詢問是否合併至帳號

/me/history：依功能篩選 → 點擊任一筆 → 以原參數重開結果頁
/me（帳號設定）→ 刪除帳號 → 二次確認 → 移除所有個資與紀錄
```

### 2.5 後台管理流程

```
/admin/login（管理員帳密）
  → 儀表板：今日測算數、分享數、會員數、熱門排行
  → 內容編輯（塔羅/籤詩/運勢/文案/文章）→ 儲存 → 前台即時生效（ISR/動態讀取）
  → SEO 設定 → 覆寫各頁 metadata
  → 會員管理 → 搜尋/停權/刪除
  → 統計報表 → 依日期區間查看各功能使用/分享/轉換
```

## 4. 結果頁 URL 設計（可重現性）

- 測算輸入以 URL-safe Base64 編碼於 `?d=` 參數（不含個資明文）
- 隨機類（塔羅/抽籤/卜卦）將抽選結果種子寫入參數 → 分享連結開啟時呈現**相同結果**
- 分享連結去除姓名等個資欄位，僅保留呈現結果所需最小資料
- 結果頁 meta `noindex`，避免個人化頁面被收錄

## 5. 響應式斷點

| 斷點 | 佈局 |
|---|---|
| < 640px | 單欄；功能卡片 2 欄格；命盤圖改直式捲動 |
| 640–1024px | 卡片 3 欄；命盤方形圖等比縮放 |
| > 1024px | 卡片 4 欄；結果頁主內容 + 側欄推薦 |
