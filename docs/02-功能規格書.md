# 星語命理平台 — 網站功能規格書

> 版本：1.0｜日期：2026-07-19
> 平台定位：整合式線上算命平台，定位為**娛樂、文化與自我探索**用途。

---

## 1. 產品概述

### 1.1 產品名稱
**星語 StarWhisper** — 整合塔羅、八字、紫微斗數、西洋占星、姓名學、生命靈數、易經、靈籤、配對、解夢、手面相的一站式命理平台。

### 1.2 目標使用者
- 20–45 歲對命理有興趣的一般大眾（以行動裝置為主，預估 70%+ 流量來自手機）
- 尋求每日運勢例行閱讀的回訪型使用者
- 透過搜尋引擎（「塔羅 愛情」「八字免費」「觀音靈籤」等關鍵字）進站的新使用者

### 1.3 核心價值主張
1. **一站整合**：12 大命理系統集中於單一平台，交叉推薦提升停留時間
2. **儀式感體驗**：抽牌動畫、洗牌互動、擲筊/擲幣動畫，重現實體占卜氛圍
3. **即時個人化**：填完資料立即產出個人化結果，無須等待或付費
4. **可分享**：每個結果可產生分享圖與分享連結，帶動社群自然流量

### 1.4 合規原則（全站適用）
- 所有結果頁固定顯示免責聲明：「本結果僅供娛樂與自我探索參考，不構成醫療、法律、投資建議」
- 禁止文案：保證發財、保證復合、疾病預測、替代醫療、誘導重大財務決策
- 個資（姓名、生日、出生時間、出生地、照片）依隱私權政策處理；未登入者的測算資料僅存於瀏覽器本機（localStorage），不上傳伺服器；登入會員可選擇是否儲存紀錄；照片僅於瀏覽器端分析展示，不上傳伺服器保存

## 2. 技術架構

| 層級 | 技術 | 說明 |
|---|---|---|
| 前端框架 | Next.js 15（App Router）+ TypeScript | SSR/SSG 對 SEO 友善 |
| 樣式 | Tailwind CSS 4 | 深藍紫金星空主題設計系統 |

## 3. 前台功能規格（12 大功能）

每個功能共通規格（下文不重複）：
- **頁面組**：介紹頁（`/[feature]`）→ 輸入頁（`/[feature]/start`）→ 結果頁（`/[feature]/result`）
- **RWD**：手機單欄、平板/桌機多欄；觸控友善（按鈕 ≥ 44px）
- **輸入驗證**：即時格式檢查（生日合法性、必填、字數限制），錯誤訊息在欄位下方
- **儀式感載入**：送出後 2–3.5 秒的主題化載入動畫（星空粒子、洗牌、擲幣等）
- **結果頁**：個人化結果 + 重新測算按鈕 + 分享（圖片下載 / 連結複製 / FB / LINE / IG）+ 收藏 + 相關功能推薦 3 則 + 免責聲明
- **SEO**：獨立 title/description、Open Graph、JSON-LD 結構化資料（WebApplication / FAQPage）

### 3.1 塔羅牌占卜 `/tarot`
| 子功能 | 路徑 | 說明 |
|---|---|---|
| 單張牌占卜 | `/tarot/single` | 78 張牌隨機抽 1 張，含正逆位 |
| 三張牌占卜 | `/tarot/three` | 過去/現在/未來牌陣 |
| 愛情塔羅 | `/tarot/love` | 3 張牌：我的心態/對方心態/關係走向，牌義用愛情向文案 |
| 工作與財運塔羅 | `/tarot/career` | 3 張牌：現況/阻礙/建議，事業財運向文案 |
| 是非題占卜 | `/tarot/yesno` | 1 張牌 → 是/否/保留 傾向判定 |
| 每日塔羅 | `/tarot/daily` | 依日期+使用者種子每日固定一張，午夜刷新 |

- **互動流程**：（可選）輸入問題 → 點擊洗牌 → 牌背扇形展開 → 逐張點選 → 翻牌動畫 → 結果
- **牌庫**：78 張完整韋特塔羅，每張含：牌名（中英）、編號、花色、正位牌義、逆位牌義、愛情/事業/財運分向解讀、關鍵字、牌面符號說明
- **結果呈現**：牌圖 + 正逆位標示 + 牌義解讀 + 綜合建議

### 3.2 八字命盤 `/bazi`
- **輸入**：出生年月日（1900–今）、出生時間（時辰，可選「不知道時辰」）、性別、出生地（用於真太陽時提示，v1 以時區提醒呈現）
- **引擎**：西曆→干支換算（年柱以立春分界、月柱以節氣分界、日柱基準日推算、時柱五鼠遁）；十神以日主推算；大運依性別與年干陰陽順逆排列，起運歲數以出生至節氣距離估算
- **結果**：四柱命盤表（天干地支+藏干+十神）、五行比例橫條圖、日主強弱、喜用神提示、大運列表（每柱 10 年）、個性/事業/財運/感情/健康五段分析（依日主五行+格局組合文案）

### 3.3 紫微斗數 `/ziwei`
- **輸入**：出生日期、出生時間（時辰必填）、性別、出生地
- **引擎**：西曆→農曆轉換 → 定命宮/身宮（寅起正月，順數生月逆數生時）→ 定五行局 → 安紫微星系（14 主星）→ 安輔星（左輔右弼、文昌文曲、擎羊陀羅、火星鈴星、地空地劫、祿存、天魁天鉞）→ 四化（依生年干）
- **結果**：12 宮命盤圖（方形宮位圖，RWD 下改為可捲動列表）、命宮/夫妻宮/財帛宮/官祿宮/遷移宮/福德宮重點分析、主星組合文案、四化提示

### 3.4 西洋占星 `/astrology`
- **輸入**：出生日期、出生時間（可選）、出生地（城市選單 → 經緯度與時區）
- **引擎**：簡化天文演算（太陽/月亮/水金火木土位置以 VSOP 簡化式或查表插值；上升星座以恆星時+緯度計算）
- **結果**：太陽/月亮/上升三主星座卡片、本命盤輪盤圖（SVG）、行星落座列表與各行星意義解讀、星座性格綜合分析

### 3.5 星座與生肖運勢 `/horoscope`
- **子頁**：每日 `/horoscope/daily/[sign]`、每週 `/weekly/[sign]`、每月 `/monthly/[sign]`、生肖 `/zodiac/[animal]`
- **產生方式**：以「日期+星座」為種子的確定性偽隨機，從後台可管理的文案池組合產生；同一天所有人看到同一星座內容相同（利於 SEO 收錄與討論）
- **結果**：綜合/愛情/事業/財運/健康五指數（1–5 星）、幸運色、幸運數字、幸運方位、短文案、宜忌小提示

### 3.6 姓名學 `/name`
- **輸入**：中文姓名（2–4 字，繁體）、性別、（命名建議模式：姓氏+期望特質）
- **引擎**：康熙筆畫字庫 → 五格計算（天格/人格/地格/外格/總格）→ 三才配置（五格數字→五行）→ 81 數理吉凶
- **結果**：五格數字與吉凶表、三才配置圖、個性/事業/感情/財運分析、新生兒命名建議（依姓氏筆畫推薦吉利筆畫組合與候選用字）

### 3.7 生命靈數 `/numerology`
- **輸入**：出生年月日
- **引擎**：數字根運算（保留大師數 11/22/33）、生日數、天賦數、流年數
- **結果**：生命靈數大卡 + 性格/天賦/人生課題/感情模式四段分析、生命靈數九宮格（先天數圈選）、流年提示

### 3.8 易經卜卦 `/iching`
- **輸入**：問題（10–100 字）+ 起卦方式三選一：隨機起卦（虛擬擲幣 6 次動畫）、數字起卦（輸入三組數字）、時間起卦（梅花易數，依當下時間）
- **引擎**：64 卦資料庫（卦名、卦象、卦辭、爻辭、白話解）；擲幣法產生本卦與變爻 → 變卦
- **結果**:本卦卦象圖（六爻符號）、卦名卦辭、變爻爻辭、變卦、白話解讀與行動建議

### 3.9 線上抽籤 `/lots`
- **子功能**：月老靈籤（100 首）、觀音靈籤（100 首）、關帝靈籤（100 首）、媽祖靈籤（60 首）
- **流程**：默想問題 → 點擊籤筒搖籤動畫 → 抽出籤支 → （可選）擲筊確認動畫 → 顯示籤詩
- **結果**：籤號與吉凶等級（上上/上/中/下…）、籤詩原文、白話翻譯、主題解讀（依籤種：姻緣/事業/健康）、建議

### 3.10 愛情配對 `/match`
- **子功能**：姓名配對 `/match/name`、生日配對 `/match/birthday`、星座配對 `/match/zodiac`、生肖配對 `/match/animal`
- **引擎**：姓名（筆畫五行互動）、生日（生命靈數相容矩陣）、星座（元素/模式相容矩陣 12×12）、生肖（六合/三合/相沖/相刑/相害關係表）
- **結果**：配對分數（0–100 動畫計數）、相處模式描述、優勢 3 點、注意事項 3 點、提升相處小建議

### 3.11 解夢 `/dream`
- **輸入**：夢境描述（自由文字，10–500 字）
- **引擎**：關鍵字字典（≥ 200 條目，分類：動物/自然/人物/場景/行為/物品/身體/情緒）→ 比對命中詞條 → 組合象徵意義
- **結果**：命中的夢境元素卡片（每個元素的象徵意義）、綜合心理向解讀、明確標示「娛樂與自我覺察參考」

### 3.12 手相與面相分析 `/palm`
- **輸入**：上傳手掌/面部照片（僅於瀏覽器端讀取展示，**不上傳伺服器**，頁面明示）+ 選擇左右手/性別
- **引擎**：v1 為娛樂性分析——以照片雜湊+使用者選項為種子，從內容庫組合個性/感情/事業/財運文案；頁面清楚標示分析方式與隱私聲明
- **結果**：分析報告 + 手相/面相知識圖解（三大主線、五官宮位介紹）

## 5. 會員系統規格

| 項目 | 規格 |
|---|---|
| 註冊 | Email + 密碼（≥8 碼）+ 暱稱；同意條款勾選（必勾） |
| 登入 | Email + 密碼；HttpOnly session cookie（30 天） |
| 密碼 | Node `crypto.scrypt` 雜湊 + 隨機 salt |
| 未登入體驗 | 全功能可用；歷史/收藏存 localStorage（上限 50 筆），登入後可合併 |
| 登入後 | 歷史紀錄與收藏同步伺服器；可預填生日資料 |
| 個資權利 | 會員中心可刪除單筆紀錄、清空全部、刪除帳號（連同所有資料） |

## 8. SEO 規格
- URL：語意化英文路徑（`/tarot/love`、`/lots/guanyin`）
- Title 模板：`{功能名}｜免費線上{類別} - 星語命理` ；每日運勢頁含日期
- 結構化資料：全站 `WebSite`+`Organization`；功能介紹頁 `FAQPage`；文章 `Article`；運勢頁 `Article`+日期
- `sitemap.xml`、`robots.txt` 自動產生；文章與運勢頁為主要收錄目標
- 結果頁 `noindex`（個人化內容），介紹頁集中權重

## 9. 非功能需求
- Lighthouse 行動版 Performance ≥ 80、SEO ≥ 95
- 首屏（介紹頁）SSG/ISR；結果計算於客戶端或輕量 API
- 支援最新兩版 Chrome/Safari/Edge；iOS/Android 行動瀏覽器
- 全站深色星空主題，文字對比度符合 WCAG AA

## 10. 商業模式（規劃，v1 不實作金流）
1. 展示型廣告位（結果頁下方、文章側欄）
2. 進階深度報告（八字/紫微完整版）預留付費牆掛點
3. 品牌合作導流（命理老師諮詢預約）預留版位
